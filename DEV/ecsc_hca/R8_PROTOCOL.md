Status: **development / synthetic descriptive investigation, not scientific qualification.**

## Frozen question

Do B0I and B0 preserve equal task-conditioned predictions and refusal behavior while the same frozen R2 trajectories are examined for absolute synthetic-label retrieval, unsupported candidate-edge contributions, and B2S divergence?

This is **not** a study of semantic memory or useful language tasks. Withheld keys come from the R2 fixture author, not independent factual adjudication. There is no new learned model, semantic authority, externally collected task corpus, or ECS_G stimulus encoding. An internally authored withheld key is a retrieval target, **not a claim that the predicted proposition is true**.

## Input and methods

Source: existing unmodified `r2_trajectories.trajectory` event sequences (arity 4/8; forward/reverse order; 20 events each, 80 total). Preserve exact source/contract authority. The scorer sees `Event.withheld`; no predictor sees it. All methods consume exactly the same `VerifiedGraph` and task except the declared admitted-only predicate restriction.

- INDEX_ONLY — canonical graph admission plus seeded keys and ordinary readout; no propagation.
- ADMITTED_ONLY — B0 closure using only ADMITTED relation predicates, never CANDIDATE.
- B0 — original exact closure, all task-allowed relations.
- B0I — retained incremental exact closure, no restart on refusal.
- B2S — bounded retained asynchronous recurrence, no restart on refusal. A scope transition may be refused; record it.

All five methods have their own logical work counters; these are not comparable machine timings or calibrated instructions. Do not normalize differences away. Graph admission is common input and **not** attributed as independent cost savings; R6 already measures shared admission work.

## Prespecified acceptance and reporting

Mechanics PASS requires all profiles produce 20 records, B0 and B0I agree exactly on refusals and the complete semantic result (except method-specific work counters), no method returns source-invalid predictions, no task/view cross-contamination, and ADMITTED_ONLY reports zero candidate evidence links. Synthetic TP/FP/FN, omission, work and refusals must be reported for **every** method, including unfavorable outcomes. No post hoc exclusion. Existing R0–R7 files must not change.

B2S is **not** required to match B0; divergence and expense are findings, not mechanics failures. INDEX_ONLY is a deliberately restricted comparator: its low recall is not evidence of semantic intelligence by propagation. ADMITTED_ONLY is an epistemic *ablation*, not a verifier of actual semantic truth.

This probe cannot establish: real-world recall utility; human-level relevance; semantic entailment; trustworthy relation extraction; ASI or language generation; optimal retention policy; current filesystem freshness after an attestation; GPU efficiency; or scientific acceptance of HCA. An R8 mechanical pass only establishes that these descriptive contrasts were generated under the declared interfaces.

## Decision rule
