# R3 prospective protocol — DRAFT_NOT_FROZEN, NOT AUTHORIZED

Created only after R2 mechanical tests completed successfully. This is a planning
artifact, not a preregistration, a new evidence tree, or permission to run science.
No R3/QUAL execution is performed. DRAFT_PROTOCOL_R1.md remains unchanged.

The prospective question is whether bounded contextual activation provides useful
task-conditioned retrieval beyond strong exact incremental computation at equal
evidence, task, graph capacity and readout authority. Retained salience is neither
semantic truth nor source attestation. Freeze source identity, generator, scorer,
observer, subjects, measurement code, schedules, allocation policy and stopping
rules before any separately authorized withheld execution. Keep R2 trajectories
strictly DEV; exclude them from scientific threshold selection and qualification.

Compare frozen B0 exact closure, B1 synchronous factor computation, B2 cold, B0I
exact incremental closure and independently named B2S. Report complete trajectories
and cumulative costs, including admission, initial cache/state construction,
invalidation, copying, schedules, readout, refusals and resets. A reset contributes
zero retained activation. Include an exact-control selection rule fixed before
measurement; do not choose a comparator after seeing which one loses.

Generate evidence and public premise roles before choosing harness-only withheld
answers. Require multiple reachable same-kind outputs, unreachable same-kind
distractors, n-ary conjunctions, independently supported branches, unsupported cycles,
two scopes and changes of source validity. Prohibit withheld keys as solver inputs.
Mutation of withheld truth must leave predictions invariant. Independently audit
every emitted label, reference, provenance field, binding constraint and source state.
Freeze the source-validation contract separately; synthetic checks confer no native
or hidden-source attestation. New authority or policy requires a separate experiment,
not an implicit rebase of R2 state.

Use two distinct analyses: whole-trajectory utility from cold start, and incremental
event cost conditional on explicitly disclosed prior state. Separate identical-task
reuse, informative same-policy successors, source/edge deletion and restoration,
seed changes, readout truncation and inadmissible transitions. Count refusals as
refusals, with no substitution. Treat partial-schedule omissions separately from
source/provenance violations. Include selective invalidation, forced reset, no
recurrence, fixed full schedules and tracked activation damage as predeclared controls.
Do not equate recovery from tracked damage with arbitrary unobserved corruption.

Candidate primary metrics are synthetic key retrieval, constraint retention, exact
distance from B0, total logical work and elapsed time. Source/binding/policy violations
are mechanical validity failures, not a scientific NONPASS label. Logical work is
not calibrated CPU compute. Freeze machine/interpreter, timing warmups, repetitions,
method ordering, aggregation, uncertainty calculation, endpoint hierarchy, task mix,
sample size and numerical utility thresholds independently before science. This
draft deliberately selects none of those values from R2 observations. The numeric
suggestions in the pre-existing R1 draft remain unapproved suggestions, not adopted
R3 criteria. If independent threshold justification is unavailable, do not run QUAL.

Separate authorization must name the frozen source/scorer/observer and approve the
complete scientific protocol. R2 grants no inference integration, training, new
source authority, hashing registry, durability, worker, model or production deployment.
