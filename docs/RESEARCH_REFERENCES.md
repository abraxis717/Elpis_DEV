# Research references: triage (2026-10-17)

External papers and code offered as possible research or engineering inputs. Nothing here is canonical authority,
an implementation instruction or evidence that Elpis has gained a capability. Each entry was triaged from the
source's own abstract and landing page (the full proofs were not reviewed): what it assumes, what it establishes,
whether any concrete Elpis gate it could serve exists today, and its disposition. **No source changed any code,
law, default or claim of this repository.** Third-party code is never copied without a checked license.

| Source | What it actually establishes (its assumptions) | Elpis surface it could touch | Disposition |
|---|---|---|---|
| [Undirected Network Coding and Faster External-Memory Integer Sorting](https://arxiv.org/abs/2610.20079) (Li, Li, Liu) | A counterexample to the Li-Li conjecture (coding beats fractional routing in undirected multiple-unicast networks) and a deterministic external-memory sort of N integers of Theta(log N) bits beating the comparison bound in some regimes, for 2B <= M <= N; correctness and bounds checked in Lean 4. Asymptotic, regime-dependent, unspecified constant. | FMS materialization and HACF I/O | **No action.** No FMS or HACF benchmark in this repository exposes an integer-sorting or block-transfer bottleneck; FMS materialization is correct and is not replaced by a coding scheme. Revisit only behind a measured bottleneck. |
| [Testing Connectedness and Edge Connectedness](https://arxiv.org/abs/2610.21299) (Palit, Pallavoor, Raskhodnikova, Varma) | Property testing in the adjacency-lists model: an optimal lower bound for connectedness testing of bounded-degree graphs (epsilon <= 1/(4d^5)) and near-tight k-edge-connectedness testers parameterized by average degree. Guarantees are epsilon-far, randomized, sublinear. | bounded HACF structural validation; adversarial graph tests | **Reference only.** HACF validation is exact and complete (it must refuse every malformed record), which an epsilon-far tester cannot replace; no HACF operation tests connectivity. Its query-complexity method may inform sampling of large adversarial inputs. Bounded-degree results do not extend to typed hypergraphs without proof. |
| [Safe-by-Design Learning via Energy-based Neural Networks](https://arxiv.org/abs/2609.36942) (Betteti, Lahijanian, Laurenti) | Continuous-time port-Hamiltonian neural ODEs with modern Hopfield energies; forward invariance through barrier functions with explicit admissible-input sets and robustness radii; empirical comparisons. | future constrained EDEN/HCA dynamics | **Future research reference.** No contextual dynamics law exists (HCA is research only; R18/R19 negative). Its guarantees are continuous-time and model-specific: they transfer to discrete ECS/HCA dynamics only with a new proof. |
| [Geometry of Learning Dynamics: GD versus Natural Gradient on the Ridge of Optimization](https://arxiv.org/abs/2609.16805) (Tamamori) | A geometric analysis of a kernel-logistic-regression-trained Hopfield memory: GD oscillates off the geodesic on a "ridge"; natural gradient follows it; faster convergence and better generalization shown experimentally. | ECS memory research; the K1 learning rule | **No change.** The canonical K1 law is qualified in its frozen regime and is not modified for a result in a different system. A natural-gradient mechanism would be a new law that must compete against K1 and strong exact-storage baselines in a pre-registered experiment. |
| [Compositional Information Geometry of Probabilistic Programs](https://arxiv.org/abs/2610.17886) (Karwowski, Nielsen, Staton) | A contravariant lax monoidal functor pulling degenerate Riemannian metrics back along first-order probabilistic programs with finite random variables (Fisher metric and ordinary pullback as special cases); the geometry is presentation-dependent, related to the realized measures by a three-level inequality. | context-to-ECS transformations; a future codec map | **Reference only.** No context-to-ECS transformation law and no codec map exist (`ECS_CODEC_UNQUALIFIED`). A mathematically attractive analogy is not an implemented law. |
| [Exponential Capacity in Multilayer Hetero-Associative Neural Networks](https://arxiv.org/abs/2607.29554) (Agliari, Barra, Ladiana, Lepre) | Capacity exponential in layer size for multilayer exponential (dense) Hopfield networks storing surjective cue-to-target maps; exact at leading order (cavity/SNR with large deviations); generalization above chance but below memorization. | recurrent FAST memory research (unqualified) | **Comparator candidate only.** ECS typed memory is exact storage with a fixed slot capacity S by construction; a capacity theorem for another network family says nothing about it. Any future recurrent-memory study keeps exact-storage and matched-memory baselines mandatory (MF memory H4 stays as recorded). |
| [An All-Transistor Physical-Learning Transformer Can Be Trained to Perform In-Context Learning](https://arxiv.org/abs/2610.12571) (Abbott, Machta) | Restored backward information flow in coupled-learning circuits; attention from sub-threshold MOSFET currents; a simple in-context task learned in simulation with approximate gradients, cross-entropy only, Lion optimiser in capacitors. | none | **No action.** Comparative inspiration only: no permission to replace ECS with attention, and no evidence that ECS performs in-context learning. |
| [Langevin Flow Maps](https://github.com/sammccallum/lfm) (code for arXiv:2610.05998) | JAX/CUDA learned transition maps for molecular dynamics and transition path sampling (MD17, alanine dipeptide, peptides). **No license file** in the repository. | stochastic transition models of ECS state | **No action; code not reusable** (no license). Any ECS application needs an explicit task and a matched comparator: H-ECS/BFM already found a simple source-fit affine predictor beating a frozen neural Bernoulli flow in its restricted task. |

Rules this triage follows: a reference is adopted only behind a concrete task, a measured need and a matched
comparator, under its own pre-registered qualification; closed results (K1 frozen regime, H-ECS R3
CLOSED_NO_ADVANTAGE_OVER_WIDTH, MF memory H4, R57-R1, the HCA record) are not reopened by analogy.
